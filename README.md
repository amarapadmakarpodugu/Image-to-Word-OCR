# Image-to-Word-OCR

A simple Python application that extracts text from an image using Optical Character Recognition (OCR) and converts it into an editable Microsoft Word document.

## 🚀 Features

- Extracts text from images using OCR
- Converts extracted text into a Word document
- Automatically creates an output `.docx` file
- Checks whether the Word document was successfully created
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Tesseract OCR
- Pytesseract
- Pillow
- Python-docx
